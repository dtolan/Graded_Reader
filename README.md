# Graded_Reader

Story library for the StoryTime app: French graded readers (CEFR A1–C1) about real people, events and places in France. Each book has 5–25 chapters at each level (history and fiction 10–25; short "everyday words" books 5–8). Text only; the app reads it aloud with the phone's own text-to-speech.

- `index.json` is the catalog. `fr/<book-id>/book.json` holds the chapter plan and key facts; `fr/<book-id>/<level>/chapter-NN.json` holds each chapter.
- `*.schema.json` define the formats.
- Books are generated by an n8n workflow and start as `status: draft` until a person has checked their `key_facts`. Draft books may contain errors.

The app and generation code live in the StoryTime repository. The app reads this repo's `main` branch through its raw URL (fixed at build time; the repo must be public). Each index entry carries a `revision`, a hash of the book's files; it must be refreshed after any change to a book, or phones keep their cached chapters.
